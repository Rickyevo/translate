Translate shows the translation of every WeChat Input Method candidate while you type pinyin, and inserts the one
you pick with Alt+1…9 or a click.

**First public release.**

### Download

`Translate-0.1.0-win-x64.zip` — portable, for Windows 10/11 x64. Unzip anywhere and run `Translate.exe`; no
installer, admin rights or Python needed. Check it against `SHA256SUMS.txt`.

Translate isn't code-signed yet: if SmartScreen warns, choose **More info › Run anyway**.

### Getting started

Type pinyin with WeChat Input Method in any app and the panel appears under the candidates. Run `Translate.exe`
again (or press Ctrl+Alt+O) to open Settings, choose a translation service, paste your API key and press
**Test connection**. Without a service, single words are still translated into English by the built-in dictionary.

Translate starts with Windows from the folder you ran it in; turn that off in Settings › General.

### Before you install

- Tested with WeChat Input Method **3.0.0.34** on Windows 11. Other WeType versions may not work; please report yours.
- Translate attaches to WeType's process (with Frida) to read the candidates, which some security software flags.
- Not affiliated with Tencent or WeChat.
