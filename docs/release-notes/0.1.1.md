Translate 0.1.1 fixes how the panel is placed and drawn on PCs other than the one it was developed on.

### Fixes

- **Panel placement on other PCs.** The panel no longer relies on WeType's bar being at one fixed spot. It finds the
  bar where WeChat Input Method actually draws it, so it lines up correctly with other WeType versions and layouts
  (including pinyin shown inline), other display scaling (125 %, 150 %, 200 %), and near screen edges.
- **No more text showing through.** The panel is now opaque by default (it was 97 %, adjustable down to 70 %, and
  other apps' text showed through it). Settings › Appearance › Panel opacity now ranges from 90 to 100 %.
- **Settings fits small screens.** It now opens at a size that fits the screen and can be resized, so Save is never
  off-screen on small laptops or at high scaling.

### Download

`Translate-0.1.1-win-x64.zip` — portable, for Windows 10/11 x64. Unzip and run `Translate.exe`, replacing 0.1.0
(quit it first from Settings › About). Your settings, keys and cache are kept. Check the download against
`SHA256SUMS.txt`. Not code-signed yet: if SmartScreen warns, choose **More info › Run anyway**.
