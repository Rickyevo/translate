Translate 0.2.2 shows both input-method connections clearly.

- Overview and About each show WeChat Input Method and Microsoft Pinyin on separate lines, with Connected or Not connected for each.
- Connection states refresh while Settings is open, including failures and adapter selection changes.
- The translation toggle and target language remain. Choose Automatic, WeChat Input Method, or Microsoft Pinyin in General.
- Includes the Microsoft Pinyin initialization fix from 0.2.1.

Quit the old app from Settings > About, unzip `Translate-0.2.2-win-x64.zip`, and run `Translate.exe`.
Your settings and saved API keys carry over.
