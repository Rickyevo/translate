Translate 0.2.3 refines Settings and makes shortcuts customizable.

- **Custom shortcuts.** Change Pause, Open Settings and Hide or show the panel in Settings › General. Translate tells you
  if a combination can't be used or another app already holds it, and warns if a saved shortcut gets taken later.
- **Clearer Overview.** One card says whether translation is on and what's translating (your service and model,
  dictionary only, or local only). Input methods are listed with their state (Ready, Not running, Off) and a switch each.
- **Leaner Settings.** About keeps what matters: version, updates, problem reports, licenses and Quit. Copy diagnostics,
  the lookup-order diagram and repeated explanations are gone.
- Hide or show the panel now follows its configured shortcut.

Quit the old app from Settings > About, unzip `Translate-0.2.3-win-x64.zip`, and run `Translate.exe`.
Your settings and saved API keys carry over.
