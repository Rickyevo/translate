Translate 0.2.0 is a much smaller app that looks exactly the same, and it no longer covers the line you're typing on
near the bottom of the screen.

### What's new

- **Microsoft Pinyin support.** Use Translate with Microsoft Pinyin, the input method built into Windows 11, as well as
  WeChat Input Method. Settings › General › Input method: *Automatic*, *WeChat Input Method* or *Microsoft Pinyin*.
- **Less than a third of the size.** Translate now uses the WebView2 Runtime built into Windows instead of bundling
  its own copy of Chromium: about **61 MB to download and 156 MB unpacked** (0.1.1: 198 MB and 474 MB). It uses
  about 16 MB of memory until you first type, and drops back to about 20 MB a few minutes after you stop.
- **The same look.** The panel, the full-text preview and Settings are pixel-identical to 0.1.1.
- **Placement fix near the bottom of the screen.** When there's no room under WeChat Input Method's bar, the panel
  goes above it — and now also above the line you're typing on, instead of covering it. Translate reads the caret
  from apps that report it (most do, including browsers and Chromium-based apps) and otherwise keeps a line's height
  clear.
- **Simpler Settings › Overview.** The three-step checklist is gone; a single *Connect a translation service* card
  appears only while no service is set up.

### Download

`Translate-0.2.0-win-x64.zip` — portable, for Windows 10/11 x64. Quit your current Translate (Settings › About ›
Quit), unzip, and run `Translate.exe`; your settings, keys and cache carry over. Check the download against
`SHA256SUMS.txt`. Not code-signed yet: if SmartScreen warns, choose **More info › Run anyway**.

Needs the Microsoft Edge WebView2 Runtime, which is part of Windows 11 and current Windows 10. If it's missing,
Translate says so and offers the download page.
