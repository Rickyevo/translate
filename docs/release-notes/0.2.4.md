Translate 0.2.4 reduces backend memory use while typing and while idle.

- **About half the backend memory in the matched test.** WeChat Input Method uses a small native observer instead
  of loading Frida by default. Backend working set was about 59 MiB instead of 117 MiB during typing and idle in a
  73-second comparison. These figures exclude the interface and input-method processes; actual use varies.
- **Bounded candidate queues.** If observation falls behind, Translate clears old candidates and waits for a fresh
  composition before allowing insertion. It reconnects automatically after WeChat Input Method restarts.
- **The same interface and shortcuts.** Candidate reading, translations and Alt+1 insertion were verified with both
  WeChat Input Method and Microsoft Pinyin. Microsoft Pinyin keeps its full UI Automation implementation.

Quit the old app from Settings > About, unzip `Translate-0.2.4-win-x64.zip`, and run `Translate.exe`.
Your settings and saved API keys carry over.
