Translate 0.2.1 fixes Microsoft Pinyin not working in Automatic or Microsoft Pinyin mode.

### Fixed

- UI Automation bindings shipped in 0.2.0 could refuse to load after a Windows DLL timestamp changed. Translate now
  loads the current system's bindings in memory, without changing Windows files or writing into the app directory.
- Release checks now verify Microsoft Pinyin initialization separately, so a working WeChat connection cannot mask
  a Microsoft Pinyin startup failure.

### Update

Quit Translate from Settings > About, unzip `Translate-0.2.1-win-x64.zip`, and run `Translate.exe`.
Your existing settings, saved API keys and cache carry over. In General, choose Automatic or Microsoft Pinyin.
If Ctrl+Alt+P is occupied by another app, pause from Settings > Overview instead; run Translate.exe again to open Settings.

Microsoft Pinyin has been tested on Windows 11; Windows 10 and the previous-version compatibility mode remain unverified.
The app requires WebView2 and is not code-signed.
